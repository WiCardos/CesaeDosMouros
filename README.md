# CesaeDosMouros 🐾

Um projeto académico dedicado ao universo felino, desenvolvido como uma plataforma conceitual para a oferta de cursos digitais inspirados em gatos.

## 📝 Sobre o Projeto

Este website foi criado no âmbito de um contexto escolar/académico e carrega uma dose saudável de humor e autocrítica. O projeto é uma **pequena sátira aos próprios lisboetas**: como todos os membros do grupo de trabalho são de Lisboa, o nome **"CESAE dos Mouros"** surge como uma piada interna e uma alusão direta ao facto de a entidade académica formadora estar sediada no **Porto** (onde, historicamente, a sul do Douro se chamavam "mouros" aos habitantes).

A plataforma simula um catálogo moderno de **cursos digitais**, utilizando uma temática criativa focada em referências felinas para dar vida à interface.

## 📁 Estrutura do Projeto

O repositório está estruturado de forma modular para organizar o desenvolvimento:

*   `components/` - Elementos e blocos reutilizáveis da interface.
*   `css/` - Folhas de estilo para o design visual e responsividade.
*   `images/` - Ilustrações, fotografias de felinos e ícones do site.
*   `js/` - Lógica de programação e interações dinâmicas em JavaScript.
*   `pages/` - Páginas secundárias (catálogo de cursos, detalhes, etc.).
*   `index.html` - Página inicial e ponto de entrada da aplicação.

## 🚀 Tecnologias Utilizadas

*   **HTML5** - Estruturação semântica do conteúdo.
*   **CSS3** - Estilização e layout adaptável.
*   **JavaScript (ES6+)** - Dinamismo e comportamento da plataforma.

## 💻 Como Executar Localmente

Para explorar o projeto no seu computador, siga os passos abaixo:

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/WiCardos/
   ```

2. **Navegar até à pasta do projeto:**
   ```bash
   cd CesaeDosMouros
   ```

3. **Abrir a aplicação:**
   * Abra o ficheiro `index.html` diretamente em qualquer navegador.
   * *Recomendado:* Utilize a extensão **Live Server** no VS Code para atualizar a página automaticamente.
